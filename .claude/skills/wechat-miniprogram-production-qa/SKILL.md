# 小程序生产验收

## 检查项
- 编译通过（无错误）
- 预览成功（无80051包体超限）
- 云函数版本正确（通过IDE HTTP API部署响应确认）
- 正式环境数据完整性（active记录数、day连续、无重复）
- 页面加载正常
- 登录流程（基础登录、手机绑定分离）
- 会员规则（Day1-3 free, Day4+ member）
- 富文本渲染（richContentHtml优先，preset兜底）
- AI输入只使用content纯文本
- ASR不受影响
- 历史作品快照优先
- 占位正文不进入正式数据
- 其他分类数量不变

## 区分
- mock结果 ≠ 真实结果
- 开发环境 ≠ 正式环境
- 静态检查 ≠ 线上验证
- 预览成功 ≠ 正式发布
