description: Diagnose WeChat Mini Program issues such as package size, media upload, cloud functions, canvas posters, preview, permissions, and platform limits.

---

Use this skill when debugging WeChat Mini Program errors.

Common focus:

- source size exceeds 2MB

- subpackage strategy

- image compression and lazy loading

- canvas poster generation

- wx.uploadFile and cloud storage

- recorder/video preview issues

- permission prompts

- cloud function logs

- openid/user role problems

- real device vs developer tool differences

Always provide:

- probable cause

- exact files to inspect

- minimum safe fix

- Codex prompt if needed

- verification steps in WeChat DevTools and real phone
